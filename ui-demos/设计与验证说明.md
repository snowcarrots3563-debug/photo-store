# 私人画师图库 · 三套 HTML Demo 设计与验证说明

更新日期：2026-09-14  
需求基线：[开发文档 v0.4](../开发文档.md)

## 1. 交付边界

本目录是 UI 选型原型，不是安卓工程。三个 Demo 使用同一套内置模拟数据；页面导航、搜索、排序、卡牌拖动、弹窗分支和列表计数会真实改变浏览器内存中的 Demo 状态。不会读取、上传或改动私人文件，也不创建正式数据库、云服务、登录、同步或端到端加密。

共同原创素材为 `assets/loop.gif`，用于验证浏览器中的真实 GIF 动画播放；其余画面素材以内嵌 SVG/渐变生成，不提取私人压缩包内容。

## 2. 方案冻结

### 方案 A：轻盈画册台

- 配色：纸张白、靛蓝、珊瑚、鼠尾草绿、柠檬黄。
- 字体：衬线标题 + system-ui 正文 + 等宽元数据。
- 布局：桌面左侧画册索引、右侧拼贴画布；移动端底部五项导航和右下角导入。
- 视觉特点：装订线、纸张层叠、彩色书签；主要操作是浏览画师与作品。

### 方案 B：暗室灯箱

- 配色：墨黑、夜蓝、紫灰、激光青、热珊瑚、雾白。
- 字体：高反差衬线标题 + system-ui 正文 + 等宽状态数据。
- 布局：桌面全屏作品舞台配左右抽屉；移动端顶部沉浸标题、胶片带、底部导航。
- 视觉特点：大幅作品灯箱；主要操作是卡牌欣赏和拖动产生的动态光晕。

### 方案 C：索引台

- 配色：目录纸、近黑、钴蓝、橙红、浅蓝、线灰。
- 字体：克制使用衬线标题 + system-ui 正文 + 等宽编号。
- 布局：桌面左索引栏 + 目录表格；移动端顶部搜索/筛选和固定底部批处理栏。
- 视觉特点：索引卡、借阅卡、引用关系标签；主要操作是检索、批量选择与整理。

三套方案的示例内容与功能范围一致，差异来自布局、视觉层级和主要操作节奏，不是单纯换色。

## 4. 功能边界标注

### 真实交互

- 画师搜索、详情进入、全部图片/作品集切换和共享图片去重展示。
- 新建空名称作品集、临时命名、改名、进入作品集和重置 Demo 数据。
- 图片多选预览、目标画师/作品集选择、模拟确认后的列表和计数变化。
- 共享图片加入其他作品集；移除仍有引用的图片；移除最后引用时的“保留图片/删除图库副本”分支。
- 卡牌 pointer 触摸/鼠标拖动驱动倾斜、光泽、镭射、厚边和阴影，松手平滑回正；查看原图入口关闭特效。
- 漫画模式与普通浏览切换、名称正序/倒序切换、当前作品集内纵向连续排列与自然排序。
- 浏览器播放本地原创 GIF；MP4 以保留媒体条目呈现。

### 模拟流程

- 相册批量导入的文件选择、进度、成功/失败、重试。
- ZIP/RAR/7z、密码包错误重试/取消、分卷缺卷/补齐、子文件夹映射预览。
- 普通图片导出、完整图库备份、空间不足/失败结果。

以上流程只改变 Demo 状态或显示流程结果，文案使用“流程演示”“模拟完成”，不代表真实解压、真实保存、真实导出或备份恢复。

### 未实现能力

- 安卓权限、真机性能、大容量 10GB 导入、真实压缩库兼容性、CRC/损坏/路径穿越安全验证。
- 真实系统相册复制、真实文件导出/备份/恢复、云端、登录、同步和端到端加密。
- MP4 内置播放器、声音、自动播放或漫画嵌入；PDF/TXT 处理。
- 生产级回收站、备份合并/替换策略，以及尚待确认的根目录散图/深层目录/同名作品集处理。
